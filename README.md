# jeongsang-ryu.github.io

Jeongsang Ryu's personal academic site — https://jeongsang-ryu.github.io

Plain static HTML/CSS, modeled on [jonbarron.github.io](https://github.com/jonbarron/jonbarron.github.io)
(and its fork, [hogyun2.github.io](https://github.com/hogyun2/hogyun2.github.io)). No build step, no
Jekyll, no Ruby — GitHub Pages serves the repo directly (see `.nojekyll`). See [CLAUDE.md](CLAUDE.md)
for where content lives and how to edit it.
